# MotoCheck

App Android (Flutter) para llevar el mantenimiento, el combustible y las refacciones de tu moto. Funciona sin cuenta; Google Drive es un respaldo opcional.

- **Documentación:** [docs/](docs/README.md) — PRD, flujo de la app, esquema de datos y plan de lanzamiento
- **Estado y stack:** [ESTADO.md](ESTADO.md)
- **Compilar y publicar:** [RELEASE.md](RELEASE.md)

```powershell
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

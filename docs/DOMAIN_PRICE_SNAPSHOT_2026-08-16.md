## Nota de interpretación

Las etiquetas “Retail” y los precios de promoción no deben confundirse con el cobro de renovación. Las páginas individuales de cada extensión mostraron una tabla con tarifas de registro y renovación; estas son las cifras de la tabla. Namecheap advierte además que podría sumarse una tarifa ICANN de US$0.20 por año para dominios afectados y que las promociones pueden cambiar. Este snapshot sirve para comparar el costo de propiedad, no para autorizar una compra.
